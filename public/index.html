Tích hợp vào các phần mềm AI (OpenAI Compatible)

API Muse 2026 hỗ trợ 100% chuẩn OpenAI. Bạn có thể sử dụng trực tiếp trên mọi ứng dụng client AI yêu thích.

🤖

NextChat (ChatGPT-Next-Web)

Mở Cài đặt (Settings) trong NextChat:

  • Endpoint: https://.../v1
  • API Key: sk-muse-...
  • Custom Models: muse-spark-1.1,muse-chat-v2,gpt-4o-muse
🔮

LobeChat

Cài đặt > AI Provider > OpenAI:

  • API Key: sk-muse-...
  • API Proxy Address: https://.../v1
  • Check Connection: Đạt chuẩn 100% phản hồi.
🍒

Cherry Studio / TypingMind

Thêm nhà cung cấp OpenAI tương thích:

  • Base URL: https://.../v1
  • API Key: sk-muse-...

Chrome Extension Trợ lý Đồng bộ Muse 2026

Cài đặt tiện ích mở rộng vào trình duyệt Google Chrome để tự động phát hiện và đồng bộ phiên đăng nhập Muse sang Web App chỉ với 1 click.

1

Tải thư mục Extension

Mã nguồn extension nằm trong thư mục /extension của dự án.

2

Bật Developer Mode

Vào chrome://extensions trên Chrome, bật công tắc Developer mode ở góc phải trên.

3

Load Unpacked

Bấm nút Load unpacked và chọn thư mục extension của dự án.

4

1-Click Auto Sync

Đăng nhập vào https://muse.ai, mở extension và bấm "Auto-Get Muse API & Sync"!
